# ReceiptBox

ReceiptBox is a privacy-first Android app for capturing, extracting and organizing purchase receipts.

## MVP
- Capture or import a receipt image
- OCR-ready receipt processing pipeline
- Extract merchant, date and total
- Edit extracted data before saving
- Store receipts locally
- Search and browse receipts
- Track categories and purchase metadata

## Stack
- Kotlin
- Jetpack Compose
- Room
- CameraX
- ML Kit Text Recognition

Package: `com.pagrey.receiptbox`
